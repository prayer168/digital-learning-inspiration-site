# CDN 類物理模擬線上驗證清單

本清單用於驗證依賴 p5.js、Matter.js、Chart.js、Three.js 或 GSAP 的物理教材。自動稽核先確認 CDN 載入、Canvas/WebGL 渲染、動畫影格變化、基本互動與 JavaScript 錯誤；人工檢查再判讀物理現象與教材說明是否一致。

## 二、自動煙霧測試

首次使用需安裝開發依賴：

```bash
npm install --save-dev playwright
npx playwright install chromium
```

執行正式網站的 CDN 線上測試：

```bash
node scripts/audit-physics.js --online
```

同時更新根目錄稽核報告：

```bash
node scripts/audit-physics.js --online --write-report
```

若需驗證預備站或其他部署網址：

```bash
node scripts/audit-physics.js --online --site-url=https://example.com/site/
```

自動測試通過的意義僅限於：正式網站可取得案例程式碼、CDN 全域物件存在、Canvas/WebGL 有渲染且影格改變、指定基本互動有觸發、沒有未捕捉的 JavaScript 錯誤。這不等同於定量物理正確。

## 三、人工共通步驟

對下列每個案例執行：

1. 用無痕視窗開啟正式網站，開啟瀏覽器開發者工具的 Console。
2. 在案例資料庫搜尋完整中文標題，開啟案例詳情並按「執行」。
3. 確認沒有顯示「程式庫載入失敗」提示。
4. 確認 Canvas 或 WebGL 畫面完整，沒有被裁切、空白或嚴重閃爍。
5. 依表格操作案例，至少觀察 5 秒。
6. 確認 Console 沒有紅色錯誤；警告需記錄內容與是否影響教材。
7. 分別以桌機寬度與手機寬度操作一次，記錄結果。
