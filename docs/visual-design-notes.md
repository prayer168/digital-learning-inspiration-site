# 視覺設計原則與版權界線

## 改版目標

2026 年視覺改版希望提升網站的沉浸感、敘事節奏與案例辨識度，同時保留教師快速搜尋、篩選及閱讀大量教材案例的效率。

## 可泛化的參考原則

本次曾觀察《星空下的黑潮島嶼》互動網站所呈現的抽象設計手法，包括：

- 深色沉浸式首屏與少量暖色重點。
- 寬字距、章節編號與敘事式排版。
- 半透明導覽與分層背景。
- 大面積留白、細線框架與克制的動態效果。

這些均屬常見的視覺設計原則，實作時已轉譯為本站自己的數位教材語境。

## 本站原創實作

- 「知識航行圖」以純 CSS 圓環、座標線及本站資料數量動態產生。
- 深海藍、冷青與沙金色票依本站科學／科技主題重新制定。
- 首屏文案、章節名稱、導航、卡片結構與互動全部沿用或改寫自本站內容。
- 案例縮圖只使用本站既有截圖與內容對應 emoji。
- 背景動態沿用本站原有 Canvas 粒子系統，並尊重 `prefers-reduced-motion`。

## 明確未使用的內容

- 未下載、複製或重製參考網站的照片、插畫、影片、音訊、Logo、標題圖或其他品牌素材。
- 未複製參考網站的 HTML、CSS、JavaScript 或動畫程式碼。
- 未使用對方的歷史文案、島嶼／燈塔構圖、選單名稱或品牌識別。
- 未建立容易使使用者誤認為與參考網站具有合作、授權或從屬關係的元素。

## 維護原則

後續新增視覺素材時，應優先使用自有作品、明確授權素材或可追溯授權來源；第三方素材需在文件中記錄作者、來源、授權方式與檢查日期。
